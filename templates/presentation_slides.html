ShopEasy E-Commerce

Full-Stack Web Architecture, Implementation & Cloud Deployment

Strategic Context

Executive Summary & Problem Statement

Bridging the gap between bloated commerce systems and modern customer expectations

Market Challenges

  • Excessive third-party dependencies leading to bloated load times and fragile build pipelines.
  • High cart abandonment driven by complicated checkouts and opaque shipping estimates.
  • Lack of responsive dark mode, live search, and verified customer review transparency.
  • Fragile deployment workflows requiring expensive database and infrastructure setups.

The ShopEasy Solution

  • Clean monolithic architecture powered by Python Flask 3.0 & SQLAlchemy 2.0 ORM.
  • Atomic stock-management preventing overselling with immediate inventory synchronization.
  • Smart promotions engine supporting promo vouchers and real-time shipping threshold meters.
  • One-click demo onboarding with pre-seeded Customer & Administrator credentials.

Measurable Impact

  • 100% Mobile & Desktop Responsive via custom CSS design system (Plus Jakarta Sans).
  • Sub-300ms first contentful paint with zero client-side JavaScript framework overhead.
  • Complete order lifecycle management: Pending → Processing → Shipped → Delivered.
  • Integrated printable official tax invoices with instant window.print() support.
Technical Foundation

System Architecture & Technology Stack

Robust separation of concerns spanning presentation, business logic, and persistence

Backend Core

  • Flask 3.0.0: Application factory, URL routing, context processors.
  • Flask-Login 0.6.3: Session authentication and user loaders.
  • Werkzeug 3.0.1: Cryptographic password hashing (scrypt/PBKDF2).
  • Gunicorn 22.0.0: Production WSGI server with multi-worker threads.

Database Layer

  • Flask-SQLAlchemy 3.1.1: Declarative relational ORM mapping.
  • SQLite 3: Zero-config ACID transactional database.
  • Relational Integrity: Foreign keys, unique constraints, cascade deletion.
  • Startup Sync: Automated schema migration and demo seeding on boot.

Frontend UI/UX

  • Jinja2: Server-rendered templates with base layout inheritance.
  • Custom CSS3: Design tokens, CSS Grid, Flexbox, and Glassmorphism.
  • Dark/Light Theme: Persistent CSS variables via localStorage.
  • Vanilla JavaScript: Debounced live search, modal overlays, toasts.

DevOps & Cloud

  • Render.com: Automated cloud containerized CI/CD pipeline.
  • Procfile: Standardized cloud WSGI process definition.
  • Cloudflare Tunnel: Zero-trust public HTTPS edge tunnel.
  • Git / GitHub: Version control with clean semantic commits.
Frontend Experience

Customer Journey & Core Storefront Features

Engineered to drive engagement, product discovery, and rapid conversion

Discovery & Live Search

Trust & Social Proof

Transaction Flow

Shopping Cart, Smart Discounts & Checkout

Frictionless conversion funnel designed to prevent abandonment

Smart Promotions & Cart Calculations

  • Session-Backed Coupon Engine: Supports percentage discounts and delivery fee waivers:
    • WELCOME10: 10% off entire cart subtotal.
    • SAVE20: 20% promotional discount for returning shoppers.
    • FREESHIP: Full waiver of the standard $5.00 shipping fee.
  • Free Shipping Progress Meter: Live progress bar showing remaining dollars required to unlock free shipping ($50 threshold).
  • Stock Boundary Protection: Interactive quantity selectors guard against exceeding live warehouse inventory.

High-Converting Checkout Flow

  • Saved Address Auto-Fill: Seamlessly pre-populates shipping address from user profile.
  • Interactive Payment Selector: Interactive tabs for Credit Card, PayPal, and Cash on Delivery.
  • Atomic Stock Management: Validates stock availability, decrements inventory atomically, creates order records, and clears cart items within a single database transaction.
  • Direct Post-Order Routing: Redirects to live visual order tracking upon completion.
Post-Purchase UX

Fulfillment Tracking & Official Tax Invoicing

Enterprise-grade customer care, auditability, and order tracking

Visual 4-Stage Fulfillment Tracker

  • Milestone Progress Stepper on /orders/<id>:
    • Stage 1: Order Placed & Confirmed.
    • Stage 2: Processing & Packing at Warehouse.
    • Stage 3: Dispatched & In-Transit (Shipped).
    • Stage 4: Delivered to Customer.
  • Order History Filter Tabs: Filter purchases by status (Pending, Processing, Shipped, Delivered).
  • Comprehensive Audit: Detailed recipient information, shipping address, and itemized receipt.

Official Tax Invoice (/orders/<id>/invoice)

  • Dedicated Invoice View: Formatted with clean corporate branding, unique invoice number (INV-0000X), order date, and customer billing information.
  • Itemized Financial Breakdown: Unit prices, quantities, subtotal, discounts, shipping fees, and grand total paid.
  • Print-Ready Styles (@media print): Automatically hides navigation, banners, and buttons when printing to paper or saving as a PDF.

Data Integrity

Database Schema & Security Framework

Defensive software engineering and secure relational data modeling

Relational Entity Models

  • User: Authentication credentials, roles, default address, phone.
  • Category & Product: Hierarchical product classification.
  • CartItem & WishlistItem: User associations with unique constraints preventing duplicate rows.
  • Order & OrderItem: Immutable historical snapshot of purchased items, prices, and status.
  • Review: User-submitted ratings (1-5) and verified buyer feedback.

Security & Hardening

  • Password Cryptography: Salted hashes generated via Werkzeug scrypt/PBKDF2.
  • Role-Based Access Control: Admin routes gated strictly by administrative permission checks.
  • Resource Ownership Verification: Prevents IDOR vulnerabilities; users can only view their own carts, orders, and invoices.
  • Input Sanitization: Form validation, length constraints, and email format verification.
DevOps & Cloud

Deployment Pipeline & High Availability

Zero-downtime automated deployment to modern cloud infrastructure

Local Development

  • Virtual environment (venv) with strictly pinned dependencies.
  • SQLite file-based database for zero-config testing.
  • Hot-reloading local server on localhost:5000.
  • Local .env file managing secret keys.

Render Production Cloud

  • Automated git-push deployment hook on master branch.
  • Gunicorn production WSGI server executing gunicorn app:app.
  • Automatic database schema migration on startup.
  • Free automated SSL certificates and custom domain support.

Cloudflare Edge Tunnel

  • Zero-trust reverse proxy tunneling local server to edge.
  • Public HTTPS URL for instant mobile and external testing.
  • QUIC protocol transport with DNS resolution checks.
  • Protection against DDoS attacks and exposed IP addresses.
